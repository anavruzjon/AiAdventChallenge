# Week0Day5 — Сравнение моделей: слабая / средняя / сильная

## Задача
Выполнить **один и тот же запрос** на трёх моделях разной «силы», замерить **время ответа, количество токенов, стоимость** и сравнить **качество, скорость, ресурсоёмкость**.

## Что делает приложение
Android-приложение (Kotlin + Jetpack Compose). Вводишь **один** запрос → он параллельно уходит во все три модели через **HuggingFace Router** (OpenAI-совместимый `chat/completions`). Для каждой модели показывается:
- ответ (с Markdown-разметкой);
- ⏱ время ответа (замер на клиенте, `System.nanoTime`);
- 🔢 количество токенов (поле `usage` из ответа: вход / выход / всего);
- 💰 оценочная стоимость (по приблизительному прайс-листу из `ModelCatalog.kt`).

Внизу — короткий **итог**: какая модель быстрее, дешевле и дала самый развёрнутый ответ.

## Используемые модели
Заданы в одном месте — [`app/.../data/ModelCatalog.kt`](app/src/main/java/ai/challenge/week0day5/data/ModelCatalog.kt). По умолчанию:

| Уровень | Модель | id |
|---|---|---|
| 🐢 Слабая | Qwen3 · 4B | `Qwen/Qwen3-4B-Instruct-2507` |
| 🚶 Средняя | Llama 3.1 · 8B | `meta-llama/Llama-3.1-8B-Instruct` |
| 🚀 Сильная | Llama 3.3 · 70B | `meta-llama/Llama-3.3-70B-Instruct` |

> Доступность конкретных моделей у HuggingFace Inference Providers иногда меняется. Если модель не обслуживается — поменяйте `id` в `MODEL_CATALOG` (например на `Qwen/Qwen2.5-*-Instruct` или `deepseek-ai/DeepSeek-V3-0324`).

## Настройка и запуск
1. Получить токен на https://huggingface.co/settings/tokens (с правами на Inference).
2. Вписать его в `app.properties`:
   ```
   HF_API_KEY=hf_ваш_токен
   ```
3. Собрать и запустить: `./gradlew :app:assembleDebug` (или из Android Studio).
4. Ввести запрос, например: «Объясни, что такое рекурсия, с примером на Python», нажать «Сравнить».

## Результаты прогона
Запрос: «Напиши сортировку массива методом слияния.»

| Уровень | Модель | Время | Токены (вход/выход/всего) | Стоимость (прибл.) |
|---|---|---|---|---|
| 🐢 Слабая | Qwen3 4B | 93745 мс | 24 / 559 / 583 | <$0.0001 |
| 🚶 Средняя | Llama 3.1 8B | 5985 мс | 50 / 521 / 571 | <$0.0001 |
| 🚀 Сильная | Llama 3.3 70B | 3321 мс | 50 / 759 / 809 | $0.00032 |



## Короткий вывод
- **Слабая (4B)** — обычно очень медленная и дешёвая, но ответ поверхностный: меньше деталей, чаще ошибки и упрощения.
- **Средняя (8B)** — баланс скорости, цены и качества; для большинства бытовых вопросов её достаточно.
- **Сильная (70B)** — самый полный и точный ответ, лучше следует инструкциям, достаточно быстро отвечает и дороже по токенам.

Вывод по ресурсоёмкости: рост качества стоит **нелинейно** — переход с 8B на 70B даёт заметно лучший ответ, но в разы увеличивает стоимость и латентность. Выбор модели — это компромисс «качество ↔ скорость ↔ цена» под конкретную задачу.
